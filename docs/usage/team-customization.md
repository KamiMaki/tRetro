# 使用指南：團隊客製化與新功能

這份指南用白話文說明 2026-06-13 新增的功能，面向實際使用 retro 看板的人。

## 1. 自訂看板區塊（每場 retro）

進到看板後，點上方控制列的 **「Sections」** 按鈕，打開「版面設定」：

- **改標題**：直接編輯每個區塊的名稱。
- **換顏色**：每個區塊可選 5 種色調（mint / cyan / violet / pink / amber）。
- **換 emoji**：輸入任何 emoji 當區塊圖示。
- **新增區塊**：按「新增區塊」會在最後面加一欄。
- **刪除區塊**：若該區塊還有卡片，系統會要求你先選一個「要把卡片移去哪一區」，
  不會直接把卡片刪掉。
- **排序**：用上下箭頭調整區塊順序。

> 你的修改會**即時同步**給房間裡所有人——大家會同時看到新的版面。
> 這些調整只影響「這一場 retro」，不會動到團隊預設或其他房間。

## 2. 團隊預設版面 / Summary Prompt / 常用 Emoji

回到 dashboard（首頁），點團隊名稱旁邊的**齒輪**打開「團隊設定」。裡面有三塊：

### 版面預設
設定這個團隊**開新房間時的預設區塊**。之後用這個團隊開的每一場 retro 都會
從這套版面開始（仍可在該場 retro 再微調）。

### Summary Prompt
「Summary Prompt」匯出（看板上的 ✦ 按鈕）會產生一段貼到 ChatGPT / Claude /
Gemini 的提示。在這裡可以改成**你們團隊自己的版本**——
- 空白 = 使用內建預設（會以灰字顯示預設內容當提示）。
- 按「回復預設」清空成預設。

### 常用 Emoji
卡片上的 emoji 反應選單預設有一組常用 emoji。在這裡可以**增刪**，調整成團隊
習慣用的那幾顆。「回復預設」會還原成內建清單。

## 3. 新手導覽

**第一次**進入任何看板時，會自動跳出 6 步教學，介紹分頁、計時器、版面設定、
引導手冊、Summary Prompt 等功能。

- 每一步都可以**「跳過」**。
- 看完或跳過後就不會再自動出現。
- 想再看一次：點控制列的 **「教學」** 按鈕。

## 4. 留言可以編輯了

把滑鼠移到自己的留言上，會看到一支**鉛筆**圖示：

1. 點鉛筆進入編輯模式。
2. 可以改文字、移除或重新貼上圖片。
3. **Enter 儲存**、**Esc 取消**。
4. 編輯過的留言會標上「已編輯」。

（Scrum Master 可以編輯房間內任何人的留言，跟刪除權限一致。）

## 5. 圖片：大小提示 + 點擊放大

- 上傳太大的圖片時，會在**還沒上傳前**就提示，並告訴你實際大小，例如
  `圖片 4.2MB 超過上限 2MB`。
- **點留言裡的圖片**會全螢幕放大預覽；按 Esc、點背景、或右上角 ✕ 關閉。

## 6. 討論模式的留言區可以拉寬

在 **Discussion** 分頁，中間卡片與右側留言區之間有一條**可拖曳的分隔線**：

- 按住拖曳即可調整右側留言區寬度（260–640px）。
- 也可以用鍵盤：聚焦分隔線後按 **←/→** 微調。
- 你選的寬度會被記住，下次進來維持一樣。
